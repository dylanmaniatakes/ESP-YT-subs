# R2 manufacturing files

Use `tinylcd_xiao_ups_carrier_r2_gerbers.zip` for the corrected R2 bare board.

Do not substitute the similarly named ZIP from `hardware/tinylcd_xiao_ups_carrier/`; that directory is the nonfunctional R1 revision.

The files under `r2_gerbers/` are the unpacked contents of the R2 order ZIP. The BOM and placement files are unchanged because the R2 correction reroutes the manually installed XIAO socket J2 and does not move SMT components.
